# OmniCourse Lens Trials

Runnable MVP demo for multimodal course-video moment retrieval, cheatsheet
generation, educational concept graphs, and an evidence-grounded AI tutor.

This project is self-contained under `Trials/omnicourse-lens-trials`.

## Quick Start

```bash
cd /home/haoqian/Data/OmniCourse-Lens/Trials/omnicourse-lens-trials
python scripts/create_demo_data.py
python scripts/rebuild_index.py
python scripts/run_backend.sh
```

Frontend instructions and full architecture notes are completed in later
milestone commits.
